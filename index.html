Mascot Vector Animation

Project Overview

Designed, rigged, and animated a mascot character in Rive to represent my personal brand. The goal was to create a fun, approachable, and professional character that communicates my creative style while being technically reusable for my portfolio website.

My Role

Solo Designer & Animator (Concept, Rigging, Animation, Branding)

Technologies Used

  • Rive (Rigging & Animation)
  • Figma (Design & Iterations)
  • Vector Illustration

Key Features

  • Round, friendly mascot designed through silhouette and color exploration
  • Rigged with a clean bone hierarchy for smooth movement
  • 3 interactive animations (idle belly tap, greeting wave, dance/jig)
  • State machine setup for event-based triggers (on_hover, on_click)

Learning Highlights

This project challenged me to combine branding, character design, and technical rigging. I gained hands-on experience with Rive’s animation workflow, including bone weighting, constraints, and state machines.

SquareSquare: 2D Puzzle Game

Project Overview

Designed and developed a minimalist 2D puzzle game prototype in Unity. The goal was to explore puzzle design principles and game theory while keeping the scope small and mechanics engaging. The final build features sliding square mechanics, multiple puzzle levels, and functional UI, embedded directly into my portfolio website as a WebGL game.

My Role

Solo Game Designer & Developer (Concept, Puzzle Design, Level Design, UI/UX, Unity Implementation)

Technologies Used

  • Unity (2D Framework, Scripting, WebGL Build)
  • Figma (Logo & UI Elements)
  • AI Tools (ChatGPT, Claude, Cursor IDE for scripting support)

Key Features

  • Core mechanic: sliding colored squares that move simultaneously until blocked
  • Progressive levels introducing hazards, bouncy walls, and multiple goals
  • Functional menus with scene and level progression tracking
  • WebGL integration for direct in-browser play on portfolio site

Learning Highlights

This project taught me how to scope a puzzle game effectively, prioritize functionality over polish, and balance puzzle difficulty through iterative testing. I also gained experience managing technical debt in Unity projects while focusing on design outcomes.

Fantasy Worldbuilding: Map of Vedalon
Map of Vedalon
Nation Flags and Emblems

Project Overview

Designed a comprehensive fantasy world through cartography, narrative worldbuilding, and visual design. Created the world of Vedalon featuring seven distinct sovereign nations, each with unique cultural identities, governments, and heraldic symbolism. The project combined research into worldbuilding conventions with hands-on design work to establish a foundation for future storytelling.

My Role

Solo Worldbuilder, Narrative Designer & Visual Designer (Research, World Concept, Map Design, Flag & Emblem Creation)

Technologies Used

  • Inkarnate (Fantasy Map Creation & Terrain Design)
  • Figma (Vector Graphics & Flag Design)
  • Research Resources (Brandon Sanderson maps, D&D materials, "A Magical Society: Guide to Mapping")

Key Features

  • Seven unique nations with distinct cultural identities, governance systems, and themes
  • High-level fantasy world map with believable geography and terrain
  • Custom vector emblems and heraldic swallowtail flags for each nation
  • Iterative design process where geography informed lore and vice versa
  • Comprehensive lore primer documenting themes, parallels, and government structures

Learning Highlights

This 93-hour project strengthened my creative worldbuilding and narrative design skills. I learned to balance ambition with scope, gained proficiency in vector graphic design without a drawing tablet, and developed confidence in creative decision-making. The symbiotic relationship between map-making and narrative development taught me how geography can drive storytelling and cultural identity.

Shonen Fighter TTRPG

Project Overview

Designed a custom TTRPG combat system inspired by fast-paced anime fighting and tournament arcs. Created to solve frustrations with traditional D&D's slow progression, this system features tournament-style battles where four players compete in dynamic arenas with transforming maps. The project combines mechanics from D&D 5e, Pathfinder, Lancer, and fighting games to deliver high-energy battles that escalate dramatically within a single session.

My Role

Solo Game Designer & Developer (System Design, Mechanical Research, Card Design, Playtesting, Iteration)

Technologies Used

  • Figma (Card Design & Feature Organization)
  • D&D 5e, Pathfinder, Lancer (Mechanical Research & Balance)
  • Daggerheart (Card System & Momentum Mechanic Inspiration)
  • Fighting Game Theory (Frame Data, Advantage States from Tekken & Street Fighter)

Key Features

  • Four distinct protagonist archetypes with unique playstyles and abilities
  • Vigilance system replacing traditional initiative with fighting game frame data
  • Momentum mechanic as unified resource system inspired by Daggerheart's Hope/Fear
  • Card-based ability system for visual clarity and reduced cognitive load
  • Five HP bars tied to power progression, unlocking stronger abilities as fighters are pushed
  • Two complete playtests with iterative mechanical improvements between versions

Learning Highlights

This 106-hour project taught me the complexities of game system balancing and the importance of playtesting. The first playtest revealed major flaws in pacing and infinite combo potential, leading to a complete overhaul of defensive mechanics and resource systems. I learned to prioritize core mechanics over aesthetics, gained experience in UX design for tabletop games, and developed skills in translating video game concepts to analog formats. The project continues beyond this portfolio piece as a Minor Skilled development.
